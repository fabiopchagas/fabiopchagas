# Fábio Chagas

**Engenheiro Front-end Sênior · Vue.js · Nuxt · TypeScript**

Mais de 8 anos em front-end e mais de 20 em desenvolvimento de software. Meu foco é arquitetura de front-end, Design Systems e performance de aplicações web de alta escala.

## Como eu trabalho

- **Arquitetura de front-end:** estrutura de projetos, padrões técnicos e organização de estado com Pinia e Vuex.
- **Design Systems:** bibliotecas de componentes como projetos independentes, documentadas no Storybook e consumidas pelas aplicações como dependência.
- **Renderização e performance:** SSR e SSG com Nuxt, Core Web Vitals e SEO.
- **Qualidade:** testes unitários com Jest e Vitest, testes de ponta a ponta com Cypress e acessibilidade (A11y).
- **Segurança no front-end:** cuidado com dados sensíveis, sessões e entradas do usuário.
- **Operação:** CI/CD, Docker, AWS e monitoramento em produção com Bugsnag, Grafana e Sentry.
- **Desenvolvimento com IA:** Claude Code no fluxo de trabalho do dia a dia.
